# Flask TODO 应用功能测试

## 这个项目是干嘛的

先用 Flask 搭了一个 TODO Web 应用，再针对这个应用写自动化测试。一共38条用例，全部通过。

做这个项目的思路是：既然找工作需要有测试经验，那就自己造一个东西来测。

## 被测应用

7个 API 端点：
- 创建 TODO
- 获取 TODO 列表/单个
- 按状态过滤
- 更新标题和状态
- 删除
- 切换完成状态
- 清除已完成项

## 测试了哪些内容

- 正常创建、空标题、超长标题（边界值1/200/201字符）
- 查询全部、按ID、不存在的ID(404)
- 更新标题和状态、无效状态值
- 删除、数量减少验证
- pending↔completed 双向切换
- 连续操作流：创建→更新→切换→删除

## 怎么跑

```bash
cd project_02_flask_todo_tests
pip install -r requirements.txt
python -m pytest -v
```

## 结果

38/38 通过，跑完只用了0.34秒。

## 学到的东西

- Flask 的 test_client 可以不启动服务器直接测API
- 先划分等价类再测边界值，测试会更有条理
- API 测试比 UI 测试快得多，也稳定得多
